# DPIMech for Android

**Open sites and apps that your internet provider blocks (Discord, YouTube, …) — only for the apps you choose.**

Android version of [DPIMech](https://github.com/halilkhrmn/dpimech). Work in progress; see
[docs/PLAN.md](docs/PLAN.md).

> DPIMech is not a VPN service. Android's VPN feature is only used to catch traffic on your phone;
> your connection still goes straight to the site, nothing passes through someone else's server.
