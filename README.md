# DPIMech for Android

**Open sites and apps that your internet provider blocks (Discord, YouTube, …) — only for the apps you choose.**

[English](README.md) · [Türkçe](README.tr.md) · [Русский](README.ru.md) ·
Website: <https://halilkhrmn.github.io/dpimech-android/> ·
Desktop version: [DPIMech](https://github.com/halilkhrmn/dpimech)

Android version of [DPIMech](https://github.com/halilkhrmn/dpimech). Runs
[ByeDPI](https://github.com/hufrea/byedpi) on the phone for the apps you pick, with the same strategies as
the desktop app. No root, no Google services, no tracking. Work in progress; see
[docs/PLAN.md](docs/PLAN.md) and [docs/PROGRESS.md](docs/PROGRESS.md).

> DPIMech is not a VPN service. Android's VPN feature is only used to catch traffic on your phone;
> your connection still goes straight to the site, nothing passes through someone else's server.

Test builds: the `dpimech-debug-apk` artifact of the [CI workflow](https://github.com/halilkhrmn/dpimech-android/actions/workflows/ci.yml).
Building from source: see [AGENTS.md](AGENTS.md#commands).
