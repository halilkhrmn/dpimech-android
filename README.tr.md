# DPIMech for Android

**İnternet sağlayıcının engellediği siteleri ve uygulamaları (Discord, YouTube, …) aç — yalnızca seçtiğin uygulamalar için.**

[English](README.md) · [Türkçe](README.tr.md) · [Русский](README.ru.md) ·
Web sitesi: <https://halilkhrmn.github.io/dpimech-android/> ·
Masaüstü sürümü: [DPIMech](https://github.com/halilkhrmn/dpimech)

[DPIMech](https://github.com/halilkhrmn/dpimech)'in Android sürümü. Seçtiğin uygulamalar için telefonda
[ByeDPI](https://github.com/hufrea/byedpi) çalıştırır; masaüstü uygulamasıyla aynı stratejileri kullanır.
Root gerekmez, Google servisleri yok, izleme yok. Geliştirme sürüyor; bkz. [docs/PLAN.md](docs/PLAN.md).

> DPIMech bir VPN hizmeti değildir. Android'in VPN özelliği yalnızca telefondaki trafiği yakalamak için
> kullanılır; bağlantın yine doğrudan siteye gider, hiçbir şey başkasının sunucusundan geçmez.

Test sürümleri: [CI iş akışındaki](https://github.com/halilkhrmn/dpimech-android/actions/workflows/ci.yml) `dpimech-debug-apk` dosyası.
