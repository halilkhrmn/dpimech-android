<p>Некоторые провайдеры блокируют сайты и приложения (Discord, YouTube…) с помощью <b>DPI</b> (глубокой инспекции пакетов). DPIMech обходит это на телефоне с помощью <a href="https://github.com/hufrea/byedpi">ByeDPI</a>: меняет вид первых пакетов соединения, и фильтр провайдера их не распознаёт.</p>
<p><b>Это не VPN-сервис.</b> Функция VPN в Android используется только для перехвата трафика на телефоне. Каждое соединение идёт напрямую к сайту: ничего не проходит через чужие серверы, IP-адрес не скрывается, сайты, заблокированные по IP, остаются заблокированными.</p>
<p>Возможности:</p>
<ul>
<li>Мастер настройки: выберите сайты, DPIMech проверит подключение и включит рабочую настройку.</li>
<li>Весь телефон для сайтов, которые часто блокируют в вашей стране, или только выбранные приложения. Остальные соединения не затрагиваются.</li>
<li>Лаборатория стратегий: проверяет стратегии на реальных сайтах с повторными раундами и показывает, что работает у вашего провайдера.</li>
<li>Автоматическая стратегия: в новой сети находит рабочую и запоминает её.</li>
<li>Шифрованный DNS (DNS over HTTPS) для приложений с обходом и блокировка QUIC по желанию, чтобы браузеры и YouTube шли через TCP.</li>
<li>Главный экран с трафиком в реальном времени, средним пингом сайтов и счётчиком DNS; то же в уведомлении.</li>
<li>Виджеты (можно по одному на профиль), ярлыки, которые включают профиль и открывают его приложение, плитка быстрых настроек.</li>
<li>Общие стратегии с версией для компьютера (Windows, Linux, macOS), обновляются без нового выпуска, плюс список сообщества.</li>
<li>Проверка блокировки через DNS, перезапуск движка при сбое, журнал и отчёт о проблеме.</li>
<li>Без root, без сервисов Google, без рекламы и слежки. Русский, English, Türkçe, فارسی, العربية.</li>
</ul>
<p>Android допускает только одну VPN одновременно: другая VPN или блокировщик рекламы на основе VPN не могут работать вместе с DPIMech.</p>
<p>Движки собираются из исходного кода внутри приложения: <a href="https://github.com/hufrea/byedpi">ByeDPI</a> и <a href="https://github.com/heiher/hev-socks5-tunnel">hev-socks5-tunnel</a>. Стратегии сообщества из <a href="https://github.com/romanvht/ByeDPIManager">ByeDPIManager</a>.</p>
