# DPIMech for Android

**Открывайте сайты и приложения, заблокированные провайдером (Discord, YouTube, …) — только для выбранных приложений.**

[English](README.md) · [Türkçe](README.tr.md) · [Русский](README.ru.md) ·
Сайт: <https://halilkhrmn.github.io/dpimech-android/> ·
Версия для компьютера: [DPIMech](https://github.com/halilkhrmn/dpimech)

Android-версия [DPIMech](https://github.com/halilkhrmn/dpimech). Запускает
[ByeDPI](https://github.com/hufrea/byedpi) на телефоне для выбранных приложений, с теми же стратегиями, что и
версия для компьютера. Без root, без сервисов Google, без слежки. В разработке; см. [docs/PLAN.md](docs/PLAN.md).

> DPIMech — не VPN-сервис. Функция VPN в Android используется только для перехвата трафика на телефоне;
> соединения идут напрямую к сайту, ничего не проходит через чужие серверы.

Тестовые сборки: артефакт `dpimech-debug-apk` в [CI](https://github.com/halilkhrmn/dpimech-android/actions/workflows/ci.yml).
